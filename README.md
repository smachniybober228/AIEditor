# AIEditor – Нейронный перенос художественного стиля

## Описание
Десктопное приложение на WPF, реализующее алгоритм Neural Style Transfer с использованием предобученных свёрточных нейросетей. Позволяет накладывать стиль одного изображения на содержание другого с гибкой настройкой параметров модели и оптимизатора.

## Технологии
- C#, .NET 8.0
- WPF (XAML)
- TorchSharp (инференс предобученных моделей)

## Ключевые возможности
- Загрузка изображений контента и стиля (поддерживаются основные форматы)
- Выбор архитектуры нейросети: **VGG-19**, **ResNet-18**, **AlexNet**
- Выбор алгоритма оптимизации: **Adam**, **RMSProp**, **Adagrad**
- Настройка гиперпараметров:
  - Коэффициент стиля (Style Scaling)
  - Количество эпох (Epochs)
  - Скорость обучения (Learning Rate)
- Отображение процесса обработки с индикацией прогресса
- Просмотр и сохранение результата
- Сохранение пользовательских настроек в JSON-файл

## Документация
Полное техническое задание, архитектура, руководство пользователя и результаты тестирования находятся в файле [Report.docx](Report.docx).

## Известные ограничения
- Приложение потребляет значительный объём оперативной памяти при работе с большими изображениями.
- Для работы требуется загрузка весов моделей из интернета (при первом запуске).
